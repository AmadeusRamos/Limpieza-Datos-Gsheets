# Limpieza de datos en Google Sheets

## Uso de Apps Script para realizar esta labor.

La limpieza de datos por mucho tiempo se realizó en Excel y macros desarrolladas para tal fin.
Con la reciente adquisición de una cuenta de Google así como una dirección de correo, se busca automatizar las tareas en este ambiente.

Este trabajo busca minimizar la intervención externa de cada archivo, con lo que se minimizará el error debido a la creación de múltiples archivos y procesos repetitivos.
Al reducir la participación externa, un sólo equipo de cómputo realizará esta tarea de forma diaria.

Los objetivos son:
- Recibir el correo y guardar el archivo `.xlsx` adjunto
- Transformarlo a archivo de Google Sheets
- Iniciar la limpieza
- Dividirlo en las partes de interés
- Enviar por correo a las personas responsables un archivo `.xlsx` para su distribución
